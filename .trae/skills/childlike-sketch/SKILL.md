# Childlike Sketch Transformation

## Core Methodology

### Naive Aesthetic Framework

将专业产品照片解构为幼童认知视角的视觉表达,核心是**刻意的不完美**:

**形态简化维度**:
- **轮廓抽象**: 复杂曲线简化为基础几何形状组合(圆形、椭圆、直线、波浪线)
- **细节删减**: 保留物体最核心的识别特征(如主体轮廓、关键功能部件位置),舍弃装饰性细节(材质质感、品牌标识、渐变效果)
- **比例失真**: 允许5-15%的比例偏差,模拟儿童对空间关系的不精确理解
- **结构拙朴**: 连接处可见断开或重叠,线条粗细不均匀(2-5px浮动)

**笔触特征维度**:
- **线条质量**: 手绘感线条,带自然抖动和速度变化
- **墨色单一**: 纯黑色线稿(#000000),无灰阶过渡或阴影
- **背景纯净**: 纯白底(#FFFFFF),无纹理或环境元素
- **笔画断续**: 关键结构线可有1-3处自然断开,强化手绘即兴感

**童趣表达维度**:
- **情感倾向**: 笨拙但不丑陋,稚拙但保持可爱
- **识别度保持**: 简化后物体主体特征仍清晰可辨
- **构图留白**: 物体占画面60-75%,四周保留充足呼吸空间

> **整体输出原则(重要)**
> 无论输入的产品是单件独立物体,还是由多个连接单元组成的物件(如手链的每一颗珠子、项链的每一节链扣、多按键乐器的每个按键),都必须将其视为**一个完整的视觉主体**来处理,输出**一张图中的一个整体简笔画**,而不是将物体拆解成若干个独立部分分别输出。
>
> 处理多单元重复结构(如珠串、链条、齿轮组)时,用简化的重复图形符号(如连续小圆圈、波浪线)示意其结构特征即可,禁止逐颗/逐节精细还原或分别生成多张子图。

## Workflow

### 1. 视觉解构阶段

**输入清单**:
- 清晰的产品照片(配饰、玩具、日常用品等实物)
- 确定物体的核心识别特征(如整体外轮廓、关键功能部件)
- 确认物体是单一整体还是多单元重复结构,明确将其作为**一个完整对象**处理

**认知简化流程**:
1. 识别物体**整体**轮廓的几何基础形状(而非逐个部件拆分识别)
2. 标记2-4个必须保留的关键细节(如把手、扣环、按键区域等)
3. 列出需删除的复杂细节(品牌文字、材质纹理、光影效果)
4. 若物体含重复单元(珠子、链节等),确定用何种简化符号统一示意,而非逐一还原

### 2. 线稿生成阶段

**执行框架**:

```
风格定义: 2-3岁幼童蜡笔画 + 黑色线稿 + 白色背景
输出范围: 整个物体作为单一完整画面输出,禁止拆分为多个局部/多张图
形态处理: [物体名称]整体简化为基础几何形状组合
线条特征: 手绘抖动感 + 粗细不均(2-5px) + 1-3处自然断开
细节保留: 仅保留[核心识别特征列表]
重复结构处理: 若含多个重复单元(珠子/链节等),用简化重复符号整体示意,不逐一精细刻画
构图要求: 物体居中,占画面60-75%,四周留白
```

**比例校准**:
- 物体主体长宽比与原图偏差≤15%
- 关键部件间相对位置保持逻辑正确(如扣环在链条上的位置)

### 3. 童趣优化阶段

**拙朴感检查维度**:
- [ ] 线条是否有自然抖动(非机械平滑)
- [ ] 是否存在笔画断开或重叠
- [ ] 细节是否过度精确(若是,需进一步简化)
- [ ] 整体是否呈现"努力但笨拙"的手绘感

**识别度审核**:
- [ ] 遮盖原图后,能否从简笔画识别出物体类型
- [ ] 核心特征是否清晰(如配饰的形态、乐器的吹嘴/琴弦/按键)
- [ ] 输出是否为**一张完整画面**,未被拆分成多张局部图

**重新生成标准**:
- 线条过于流畅规整(缺乏手绘感) → 增加抖动和断续
- 细节过多(接近写实) → 删减至2-4个核心特征
- 比例严重失真(物体不可识别) → 重新校准主体形状
- 输出结果被拆分成多个局部/多张子图 → 重新按"整体输出原则"合并为单一画面

## Key Constraints & Standards

### 绝对规则
- **色彩锁定**: 仅使用纯黑(#000000)线条 + 纯白(#FFFFFF)背景,禁止任何灰阶、彩色或渐变
- **单物单图**: 一张图仅包含一个物体主体,禁止多物体组合或场景化
- **整体成图**: 一个物体必须在一张图中完整呈现,禁止将同一物体拆解为多个部分分别输出(例如手链不可拆成逐颗珠子的多张图)
- **年龄锚定**: 绘画水平严格对应2-3岁幼童(学龄前),不可升级至4-5岁的精确度

### 简化程度标准
- **细节数量**: 每个物体保留2-4个核心识别特征,删除所有装饰性/次要细节
- **线条数量**: 总笔画数≤原物体视觉复杂度的30%(如含20颗珠子的手链简化为一段带5-7个小圆圈的连续弧线)
- **曲线简化**: 复杂曲线转换为2-3段折线或单一弧线

### 手绘质感标准
- **线条粗细**: 2-5px浮动,禁止统一线宽
- **抖动幅度**: 线条边缘偏移≤3px,模拟手部不稳
- **断续处理**: 每个物体允许1-3处自然笔画断开,位置随机

### 构图规范
- **物体占比**: 60-75%画面,过小显空洞,过大显拥挤
- **留白分布**: 上下左右均匀留白,物体居中
- **方向一致**: 物体朝向与原图保持一致

## Example

**输入**: 一件带有多个连接珠饰的手链产品照(金属质感、珠子按序排列、有装饰性扣环)

**输出**:
- **主体形状**: 一条弯曲的手链整体轮廓(单一黑色弧线,带自然抖动),**作为一张完整画面输出,而非逐颗珠子单独成图**
- **保留特征**: 手链闭合弧形轮廓 + 用一串简化小圆圈示意珠子排列 + 一个简化扣环符号
- **删除元素**: 金属光泽、珠子表面纹理细节、扣环机械结构、品牌刻字
- **线条特征**: 粗细2-4px波动,手链弧线有1-2处自然断开
- **构图**: 手链占画面65%,居中,整体闭合形态清晰可辨
