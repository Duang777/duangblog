# 音乐怎么放

网站首页 `/` 就是音乐页，点右上角的进入博客才到博客首页 `/blog/`。旧的 `/music/` 会跳回 `/`。

首页往下有两块歌单：

- 曲目：网易云上在听的歌，数据在 `src/data/netease.ts`，用脚本同步，见下面的网易云一节。
- 我的小样：自己录的歌，来自 `src/content/tracks/`。只有至少一首不是草稿的时候才出现，位置在曲目上面。

唱机按这个顺序放：先放我的小样，再放曲目里能在站内播的歌。

## 网易云：曲目

### 同步一个歌单

1. 在网易云里把歌单设成公开。私密歌单接口拿不到。
2. 复制歌单链接，形如 `https://music.163.com/playlist?id=123456`、`https://music.163.com/#/playlist?id=123456` 或 `https://y.music.163.com/m/playlist?id=123456`，后面带的 `uct2` 之类追踪参数会被忽略。只写数字 id 也行。`163cn.tv` 这种短链接脚本不认，先在浏览器里打开，用跳转后地址栏里的链接。
3. 在仓库根目录跑：

```sh
node scripts/netease.mjs playlist "https://music.163.com/playlist?id=123456&uct2=..."
```

脚本会用歌单里的全部歌、按歌单里的顺序重写 `src/data/netease.ts`。已经在列表里的歌，原来的短评和加入日期会留着；不在歌单里的歌会被拿掉，终端里会列出来。同一个歌单再跑一遍，文件不会变。歌单里加了新歌，重跑同一条命令就行。

### 单首加和删

```sh
node scripts/netease.mjs add "https://music.163.com/song?id=472973563&uct2=..." "一句话短评，可以不写"
node scripts/netease.mjs add 472973563          # 只写 id 也行
node scripts/netease.mjs --remove 472973563     # 撤下
```

歌曲链接认 `music.163.com/song?id=`、`#/song?id=`、`y.music.163.com/m/song?id=` 和纯数字 id。新加的歌排在最前面。再跑一次不带短评，原来的短评会留着；短评传空字符串 `""` 就是删掉。

`src/data/netease.ts` 不要手改，脚本每次都会整段重写那个数组。歌名、歌手、专辑、封面和时长都从网易云的接口取。注意 `playlist` 是整表替换，之前用 `add` 单独加、但不在歌单里的歌会被拿掉。

### 哪些歌能在站内放

- 免费歌（接口里 `fee` 是 0 或 8）在 SIDE A，点唱片、点那一行或者按空格都会在站内的唱机里放，示波器、首页大字和封面都跟着这首歌动。
- VIP 歌（其他 `fee`）在 SIDE B，挂一个 VIP 小标签，点那一行会在新标签页打开网易云的歌曲页。网易云不给站外放 VIP 歌，这里也不去绕。

能不能放是同步那一刻按 `fee` 判断的。网易云之后可能把一首免费歌改成 VIP，那时站内会在放之前问到它放不了：那一行变灰，多一个去网易云听的链接，唱机直接跳到下一首能放的。这次访问里不会再试这首。一首都放不了的时候，点唱片只会提示还没有能在这里放的歌。

封面统一用 `?param=400y400` 取 400 像素的小图，按黑白显示，不带 Referer。

### `/api/netease/<id>` 是干什么的

浏览器要能读到音频数据，唱机的示波器和大字才会动，这要求音频是带 CORS 头的。网易云免费歌的外链地址 `https://music.163.com/song/media/outer/url?id=<id>.mp3` 会 302 跳到 `m701.music.126.net` 这类媒体地址。媒体地址本身带 `Access-Control-Allow-Origin: *`，但那个 302 不带，浏览器用 CORS 模式请求外链地址会直接失败；不用 CORS 模式又能放，可是读出来的数据全是零。

所以站点自己有一个很小的接口，在服务器上替浏览器走一次这个跳转，把最终的媒体地址交给唱机：

- 线上是 Cloudflare Pages Function，文件在 `functions/api/netease/[id].ts`。Pages 会把仓库根目录（`wrangler.toml` 旁边）的 `functions/` 当成函数目录，`dist/` 里没有这个路由。
- 本地 `astro dev` 没有 Functions 运行时，`astro.config.ts` 里一个只在开发服务器上生效的集成挂了同一个路由。
- 两边调用的是同一个模块 `src/lib/netease-resolve.ts`。id 只能是数字，否则返回 400。跳到 `music.163.com/404` 或者没有跳转的，返回 `{"playable": false}`；能放的返回 `{"playable": true, "url": "https://..."}`。

媒体地址大约 25 分钟后过期，接口带 `Cache-Control: public, max-age=600`。暂停超过 20 分钟再继续，唱机会重新要一次地址，从暂停的位置接着放。

本地想在 Functions 运行时里试接口，可以先 `pnpm exec astro build`，再 `npx wrangler pages dev dist`，然后访问 `http://127.0.0.1:8788/api/netease/1857979755`。

## 我的小样：自己的歌

### 模板

`src/content/tracks/` 里的 `sketch-01.md` 到 `sketch-04.md` 是模板，都写了 `draft: true`，不会出现在首页，也没有曲目页。要发自己的歌，复制一份改名，填好字段，删掉 `draft` 那一行。

### 加一首歌

1. 把音频放进 `public/music/`，比如 `public/music/night-drive.mp3`。
2. 在 `src/content/tracks/` 新建 `night-drive.md`。
3. 写好 frontmatter，正文写这首歌的内页说明（Markdown 就行）。

```md
---
title: "Night Drive"
side: "A"
no: 4
releaseDate: 2026-11-02
status: demo
description: "一句话介绍，会显示在曲目表里。"
audio: "/music/night-drive.mp3"
# qishui: "https://qishui.douyin.com/s/xxxxxxx/"
cover: "./covers/night-drive.jpg"
bpm: 92
key: "E minor"
duration: "3:42"
tags: [吉他, 夜里]
---

这里写录音的过程、用了什么乐器、想说的话。
```

### 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| title | 是 | 歌名 |
| side | 是 | `"A"` 或 `"B"` |
| no | 是 | 这一面里的顺序，编号显示成 A1、B2 |
| releaseDate | 是 | 日期，写成 `2026-11-02` |
| status | 是 | `released` 发行、`demo`、`sketch` 草稿 |
| description | 是 | 一行介绍 |
| audio | 否 | `public/` 下的路径，以 `/music/` 开头 |
| qishui | 否 | 汽水音乐的分享链接，见下面一节 |
| cover | 否 | 封面图，相对这个 md 文件的路径，比如放在 `src/content/tracks/covers/` |
| bpm | 否 | 默认 96 |
| key | 否 | 默认 `"A minor"`，只看开头的音名 |
| duration | 否 | `"3:42"`。不写的话，有音频就在浏览器里读出来 |
| tags | 否 | 默认空 |
| draft | 否 | `true` 时不上线：首页、唱机和曲目页都不会有它 |

### 没有音频会怎样

不写 `audio` 也能放。播放器会按这首的 `bpm` 和 `key` 生成一段循环：底鼓、闭镲、贝斯和一条琶音，音都取自这个调的小调五声音阶。同一个文件名每次生成的旋律都一样，换文件名就换一段。时长那一栏显示 LOOP，会一直循环到暂停或切歌。

没有 `cover` 时，曲目页会按文件名生成一张黑白封面。

### 汽水音乐

在 `qishui` 写上汽水音乐的分享链接（在 App 里点分享，复制链接，形如 `https://qishui.douyin.com/s/xxxxxxx/`），我的小样里那一行会多一个汽水小标签，曲目页会多一个在汽水音乐收听的按钮。两处都在新标签页打开汽水音乐。

能做的只有链出去，歌没法在站内播：

- 汽水音乐没有官方的嵌入播放器，也没有开放接口。
- 分享页的响应头带 `X-Frame-Options: SAMEORIGIN`，别的网站用 iframe 嵌进来，浏览器会直接拒绝。
- 分享页里只有歌名、封面这些信息，没有音频地址。音频走带签名的接口，不少歌还要会员。去抓这个地址或者用第三方解析，既不稳定也不合规矩，所以这里不做。

自己的歌想在站内播，同时又能去汽水听，推荐这样放：

1. 从工程里导出母带，存成 mp3 或 m4a，放进 `public/music/`。
2. 在 md 里同时写 `audio` 和 `qishui`。

站内播放用的是 `audio` 那个文件，唱机、示波器和首页的大字都跟着它动，`qishui` 只管那个链接。只写 `qishui` 不写 `audio` 的话，站内播的还是生成的循环。

## 小提示

- 文件名以 `_` 开头的 md 不会被读取，可以拿来放草稿模板。
- 换主题（顶栏那个半黑半白的圆）就是黑白切换，音乐区不会出现别的颜色。
- 快捷键：空格播放暂停，J 或右方向键下一首，K 或左方向键上一首。焦点不在按钮或链接上时，按 B 或回车进入博客。
